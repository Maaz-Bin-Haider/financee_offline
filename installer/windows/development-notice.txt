Financee Offline — Windows x64 development setup

This is an unsigned development package for local owner review, not a customer-certified release. Real Windows 10/11 installation, reboot, repair/uninstall and offline acceptance are pending. Windows 10 runtime qualification remains a release blocker; this prototype refuses unqualified Windows 10 installation.

The installer copies program files under your user account. Financee Setup checks prerequisites and imports a separately verified local runtime archive or downloads it only when a release URL has been configured. This development repository does not publish a download.

Docker Desktop and Windows/WSL prompts require your own review and consent. Financee does not accept their terms, disable Windows protections, replace another runtime, remove existing WSL distributions or restart your computer automatically. Review current OS servicing eligibility in Docker's official requirements.

Your business data and backups stay in the separate customer folder you choose. Uninstall stops verified Financee services and removes program files; customer folders, backups, containers, images and data volumes are retained. Keep additional backup copies on another device.

Manual Upgrade in Setup accepts only reviewed schema-2 0.5/0.7 sources and retains a paired rescue ZIP, previous program/images and old DB/media. Close old maintenance and disable its optional sign-in startup before applying; enable startup in the new app only after success. Interrupted upgrades use Recover Interrupted Upgrade in the matching new setup. Native Windows upgrade/device acceptance is pending.
