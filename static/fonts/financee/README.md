# Financee Sans 1.0

Derived from DejaVu Sans 2.37, renamed for this product, with AFN U+060B and
SAR U+FDFC currency outlines from Noto Naskh Arabic and BDT U+09F3 from Noto Sans
Bengali. All catalogue currency symbols are checked in all four bundled styles.
Arabic letter outlines missing in DejaVu's italic faces are supplied from its
regular face for the AED symbol. The original fonts are not modified in place.
The source paths/versions and SHA256 hashes are recorded in MANIFEST.json.
Rebuild with scripts/build_pdf_fonts.py and FontTools; customers need no tooling.

The derived font files and embedded font payload remain available under SIL OFL
1.1, with the original DejaVu/Bitstream/Arev notices preserved. See OFL.txt and
DejaVu-LICENSE.txt. Never sell these font files separately.

Official sources:

This is a currency-symbol coverage guarantee, not universal coverage of every
writing system. The Phase 3 complete asset/font audit remains separately gated.
